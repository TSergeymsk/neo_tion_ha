# Neo Tion для Home Assistant

Современная интеграция для управления бризерами Tion и датчиками MagicAir через облачный API.

## Установка
1. Добавьте репозиторий в HACS как Custom Repository.
2. Установите интеграцию.
3. Перезагрузите Home Assistant.
4. Настройки → Устройства и службы → Добавить интеграцию → Neo Tion.
5. Введите email и пароль от аккаунта Tion MagicAir.

## Возможности
- Climate-сущность для каждого бризера (вкл/выкл, скорость, целевая температура).
- Сенсоры CO₂, температуры и влажности для MagicAir.
- Централизованное обновление через `DataUpdateCoordinator`.

## Отладка
Скачайте диагностику из интерфейса интеграции для получения состояния координатора и сырых данных API.
