# Neo Tion для Home Assistant

Современная интеграция для управления бризерами Tion и датчиками MagicAir через облачный API.

## Установка

1. Добавьте репозиторий в HACS как Custom Repository (категория Integration).
2. Установите интеграцию **Neo Tion**.
3. Полностью перезапустите Home Assistant.
4. Настройки → Устройства и службы → Добавить интеграцию → **Neo Tion**.
5. Введите email и пароль от аккаунта Tion MagicAir.

## Возможности

- Climate-сущность для каждого бризера (вкл/выкл, скорость 1–6, целевая температура).
- Сенсоры CO₂, температуры и влажности для MagicAir.
- Централизованное обновление через `DataUpdateCoordinator` — один запрос к API на цикл.
- Диагностика: Настройки → Устройства и службы → Neo Tion → ⋮ → Скачать диагностику.

(`_LOGGER.exception`) — причина всегда видна.
